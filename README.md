# Calcolo Giorni e Date

App Android per calcolare intervalli tra date e scadenze.

## Requisiti
- Compatibilità minima: Android 7.0 (API 24)
- Sviluppo: Kotlin e Jetpack Compose
- Elaborazione e dati in locale: nessun account richiesto

## Compilazione
La compilazione automatica tramite GitHub Actions verrà configurata nel progetto. Il workflow userà Gradle installato nell'ambiente CI; per ora non è incluso il Gradle Wrapper.
